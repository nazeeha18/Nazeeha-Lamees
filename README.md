# Nazeeha Lamees - FSD Assignment 1

## Personal Portfolio Web Application

Technologies:
- HTML5
- CSS3
- Bootstrap 5
- JavaScript ES6+

### Features
1. Semantic Home, About, Education, Skills, Projects, Achievements and Contact sections.
2. Responsive mobile-first design using media queries.
3. Bootstrap navbar, grid, buttons, cards, table, forms and alerts.
4. Light/Dark theme switching using JavaScript and localStorage.
5. Project filtering using JavaScript DOM manipulation.
6. Client-side form validation with dynamic success/error messages.
7. Accessible labels, semantic elements and ARIA-friendly controls.
8. Local profile SVG image with alternative text.

### Run
Open `index.html` in a browser. Internet access is needed for Bootstrap CDN files.

### GitHub
Create a repository, upload all files, and optionally enable GitHub Pages.
